# Gabsinto preset pack

AI-generated portrait renders of the repository owner (Gabriel), supplied by
the owner for use as a hidden avatar set in this local-only party-game app.

- Not distributed. The whole platform runs on a LAN with no accounts and no
  internet; these files never leave the host machine.
- Unlocked by typing the name "Gabsinto" on the join screen.
- Regenerate with `python tools/build-gabsinto.py` (sources in
  `tools/gabsinto-source/`).
