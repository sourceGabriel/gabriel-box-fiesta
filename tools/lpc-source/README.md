# tools/lpc-source

Vendored subset of the Universal LPC Spritesheet Character Generator (https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator)
used to build `ui/src/avatar-assets/`. Only the south-facing idle frames, the body/hair/eye/cloth palettes, and the matching credits are kept.

Regenerate the pack with `python tools/build-avatars.py`.
