# Attract-screen posters

`attract-bg.webp` (landscape) and `attract-bg-portrait.webp` (portrait) —
AI-generated posters supplied by the repository owner for the host
attract/start screen of this local-only party-game app.

- Not distributed. The platform runs on a LAN with no accounts and no
  internet; the files never leave the host machine.
- Source renders in `gabriel-source/` (gitignored). Rebuild with
  `python tools/build-attract-bg.py`.
- The posters carry the wordmark + tagline. The attract screen is pure
  presentation (tap / any key to continue); the room code, QR code and
  connected-phone count belong to the lobby only.
